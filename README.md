# FundRadar (ทุนเรดาร์)

ระบบติดตามประกาศทุนวิจัย/นวัตกรรมใหม่จาก NRIIS (https://nriis.go.th/rss.aspx) อัตโนมัติ

## วิธีทำงาน
- `fundradar.py` ดึง RSS แล้วเทียบกับรายการที่เคยเห็นแล้วใน `data/seen.json`
- ถ้ามีประกาศใหม่ → เขียนรายงานไว้ที่ `reports/YYYY-MM-DD.md`, พิมพ์สรุปออกทาง stdout, และเด้ง**การแจ้งเตือนบน macOS**
- รันครั้งแรกจะถือว่าทุนทั้งหมดในตอนนั้นเป็น baseline (ยังไม่แจ้งเตือน) เพื่อไม่ให้แจ้งย้อนหลังทุกอันพร้อมกัน — ทำไปแล้วตอนติดตั้ง (baseline 100 รายการ ณ 2026-08-04)

## แดชบอร์ด
เปิดดูทุนทั้งหมดแบบภาพรวมได้ที่ `dashboard/fundradar_dashboard.html` (เผยแพร่เป็น Claude Artifact ไว้ให้แล้ว)
มี Dashboard, Grants Directory (ค้นหา/กรอง), Saved Grants (บันทึกด้วย localStorage ของเบราว์เซอร์), Analytics, Settings

หน้านี้เป็น **ภาพนิ่ง (snapshot)** — รีเฟรชข้อมูลด้วยคำสั่ง:
```bash
cd /Users/papup/NRIIS
python3 build_dashboard.py
```
แล้วขอให้ Claude เผยแพร่ไฟล์ `dashboard/fundradar_dashboard.html` เป็น Artifact ใหม่อีกครั้ง (ลิงก์เดิม)

### การสกัดข้อมูลเชิงลึก (data/extracted.json)
แต่ละประกาศมีปุ่ม **"ดูรายละเอียด"** เปิดแผงข้อมูลเชิงลึก (กลุ่มเป้าหมาย, งบสนับสนุน, กำหนดปิดรับ, วัตถุประสงค์, คุณสมบัติ) —
ข้อมูลนี้มาจากการที่ **Claude อ่านและสกัดเนื้อหาประกาศจริงทีละฉบับ** (ไม่ใช่ regex ธรรมดา) เก็บไว้ที่ `data/extracted.json`
ครอบคลุม 100/100 รายการ ณ ตอนสร้าง (ก่อนหน้านี้จับกำหนดปิดรับด้วย regex ได้แค่ 8 รายการ, ตอนนี้ 35 รายการ)

**ข้อจำกัดสำคัญ**: ขั้นตอนนี้ไม่ได้รันอัตโนมัติพร้อมกับ `fundradar.py`/`build_dashboard.py` เพราะต้องใช้ Claude อ่านเนื้อหาจริง (ไม่มี LLM API key ผูกไว้ในระบบอัตโนมัติ) —
ประกาศใหม่ที่เข้ามาหลังจากนี้จะ**ยังไม่มีรายละเอียดเชิงลึก** จนกว่าจะขอให้ Claude รันการสกัดซ้ำ (เปิดการ์ดของประกาศนั้นจะเห็นข้อความแจ้งว่ายังไม่มีข้อมูล พร้อมลิงก์ไปประกาศต้นฉบับแทน)
สำหรับรายการอื่นที่ยังไม่ผ่านการสกัด ระบบจะ fallback ไปใช้การจับคำสำคัญแบบเดิม

หมายเหตุความแม่นยำ:
- **กำหนดปิดรับ**: สกัดเฉพาะกรณีที่ประกาศระบุวันปิดรับชัดเจน (ไม่ใช่วันที่อื่นที่ไม่เกี่ยวข้อง) หากประกาศไม่ได้ระบุจะไม่เดาให้ — และรองรับกรณี "ปิดรับไปแล้ว" ด้วย (ฟีดเก็บประกาศเก่าที่หมดเขตแล้วไว้ด้วย)
- **งบสนับสนุน**: แสดงเฉพาะกรณีที่ประกาศระบุวงเงินสูงสุดชัดเจน (5/100 รายการ) รายการอื่นแสดง "ไม่ระบุในประกาศ" แทนการเดา
- **หมวดหมู่/วัตถุประสงค์/คุณสมบัติ**: สรุปจากการอ่านเนื้อหาจริง อาจมีคลาดเคลื่อนได้บ้างเช่นเดียวกับการสรุปความด้วยคนอ่าน ควรยึดประกาศต้นฉบับเป็นหลักเมื่อจะตัดสินใจสมัครจริง

## รันอัตโนมัติทุกวัน (ตั้งไว้แล้ว)
ติดตั้งเป็น macOS LaunchAgent ที่ `~/Library/LaunchAgents/com.fundradar.nriis.plist`
รันทุกวันเวลา **08:07 น.** (เวลาเครื่อง) โดยอัตโนมัติ แม้ไม่ได้เปิด Claude Code อยู่ก็ตาม

คำสั่งที่ใช้จัดการ:
```bash
# ดูสถานะ
launchctl print gui/$(id -u)/com.fundradar.nriis

# สั่งรันทันที (ทดสอบ)
launchctl kickstart gui/$(id -u)/com.fundradar.nriis

# ปิดการทำงานอัตโนมัติชั่วคราว
launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/com.fundradar.nriis.plist

# เปิดกลับมาทำงานอีกครั้ง
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.fundradar.nriis.plist

# แก้เวลาที่รัน: แก้ไขค่า Hour/Minute ในไฟล์ .plist แล้ว bootout + bootstrap ใหม่
```

Log การรันแต่ละครั้งอยู่ที่ `logs/fundradar.log` และ `logs/fundradar.err.log`

## ตั้งค่าแจ้งเตือนทางอีเมล (ทางเลือก)
ค่าเริ่มต้นแจ้งเตือนผ่าน macOS notification เท่านั้น (ยังไม่มีการเชื่อมต่อบริการอีเมลใด ๆ ไว้ล่วงหน้า)
ถ้าต้องการให้ส่งอีเมลจริงไปที่ kpupcenter@kpup.one ด้วยเวลาพบทุนใหม่:

1. คัดลอก `config.example.json` เป็น `config.json`
2. กรอกข้อมูล SMTP ของคุณเอง **ในไฟล์โดยตรง** (ไม่ต้องส่งรหัสผ่านมาทางแชท)
   - ถ้าใช้ Gmail: ต้องสร้าง "App Password" ที่ https://myaccount.google.com/apppasswords (ต้องเปิด 2-Step Verification ก่อน) — ห้ามใช้รหัสผ่านบัญชีจริง
3. ครั้งถัดไปที่พบทุนใหม่ ระบบจะส่งอีเมลอัตโนมัติ

## โครงสร้างไฟล์
```
fundradar.py           สคริปต์หลัก (ดึง RSS, เทียบของใหม่, เขียนรายงาน, แจ้งเตือน)
build_dashboard.py     สร้างหน้าแดชบอร์ดจากข้อมูล RSS + data/extracted.json
emailer.py              โมดูลส่งอีเมล (ใช้เมื่อมี config.json)
config.example.json     ตัวอย่างการตั้งค่าอีเมล
data/seen.json          รายการทุนที่เคยเห็นแล้ว (auto-generated)
data/extracted.json     ข้อมูลเชิงลึกที่ Claude สกัดจากเนื้อประกาศจริง (อัปเดตเมื่อขอให้ Claude รันซ้ำ)
dashboard/template.html เทมเพลตหน้าแดชบอร์ด (แก้ดีไซน์/ฟีเจอร์ที่นี่)
reports/                 รายงานทุนใหม่รายวัน (auto-generated)
logs/                    log การรันของ launchd
```
